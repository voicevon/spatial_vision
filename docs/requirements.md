# 系统边界、物理工况与硬性约束

> **定位**：定义 `spatial_vision` 覆盖的全部子系统边界、现场物理工况、硬件接口协议与不可违背的安全红线。  
> **读者**：开发者与 AI 编程助手。

---

## 1. 系统边界与子系统范围

`spatial_vision` 是面向**绿芦笋自动化上料与分拣产线**的工业视觉感知、空间标定与多执行器控制平台，覆盖五大业务子系统：

1. **工位与空间场景管理 (`workspace`)**：多工位物理沙盒隔离、硬件/分辨率锁定、多机构坐标系树与 3D Smart ROI 建模。
2. **相机内参与 AprilTag 空间建图 (`calibration`)**：标定板内参求解、多视角 AprilTag 16h5 两阶段 BA 空间平差、世界基准对齐与在线自定位。
3. **视觉感知与几何测量 (`vision`)**：
   - 多根堆叠芦笋的 3D RGB-D 顶层抓取位姿解算；
   - 纯 2D 多算法管线对比与脊线/遮挡分离框架；
   - 单根芦笋 ROI 内白绿分界识别、绿色有效长度与特征直径测量。
4. **SCARA 上料机械臂控制 (`control` + `devices`)**：Smart ROI 进料/落料分选调度、三段式防撞 G-code 规划与 MKS Base Marlin 串口闭环。
5. **分离轮与网络摄像机协同 (`control` + `tools`)**：8 通道 ESP32 分离轮（`flux_isolate_wheels`）MQTT 节拍调度与连续生产；手机网络摄像机（`android_as_camera`）MQTT 远控与 RTSP 拉流调试。

## 2. 物理工况与硬件规格

| 组件 | 选型 / 协议 | 关键工况与技术参数 |
| :--- | :--- | :--- |
| **3D 深度相机** | Intel RealSense D435（主动红外双目） | 顶置大倾角俯视（$\pm 30^\circ$）；推荐工作距离 $550 \sim 700\text{ mm}$（避开 $<280\text{ mm}$ 盲区）；支持 `1280x720` / `1920x1080` |
| **通用 / 网络相机** | USB 摄像头；手机 NetCamera（MQTT + RTSP） | USB 走 `CameraService` 统一后端；手机网络摄像机走 `rtsp://{ip}:8554/live`（TCP 交错）+ MQTT `camera/+/state` & `camera/{id}/cmd` |
| **空间标靶体系** | AprilTag `16h5`（ID `0~29`） | 推荐物理边长 $50\text{ mm}$（以工位 `tag_whitelist.yaml` 的 `tag_default_size_mm` 为唯一真理源），需 100% 原比例硬基板打印 |
| **SCARA 上料机械臂** | 4 轴 SCARA + 气动夹爪（MKS Base V1.6 / Marlin 2.0+） | USB 虚拟串口 `115200 bps`；绝对坐标模式 `G90`；夹爪指令 `M3`（张开）/ `M4`（闭合） |
| **分离轮执行器** | ESP32 8 托架步进分离轮（`flux_isolate_wheels`） | MQTT 协议 v1.3（Broker 默认 `voicevon.vicp.io:1883`，前缀 `flux/loader`）；支持 `load`（8 托架数量 + `0.1x~2.0x` 速度倍率）、`motor`、`multi` 指令 |
| **分发翻料机构** | ESP32 8 级级联步进翻料器（`flux_dealer`） | BLE 4.2/5.0 单播下发分拣等级槽位 `Target Grade: 1~8` |
| **计算平台** | Windows 10/11 x64（兼顾 Linux） | Python 3.10+；实时视窗目标 30fps @ 1080P；单帧感知推理 $\le 200\text{ ms}$ |

## 3. 核心物理难点与应对策略

| 场景 | 物理难点 | 工程应对 |
| :--- | :--- | :--- |
| **堆叠芦笋抓取** | 传送带倾角导致深度梯度；并排贴合粘连；湿润表面红外反光黑洞；多层交错叠压 | 传送带 RANSAC 平面纠偏 → 3D 浮凸初筛 + 黑帽暗缝切分 → 脊线高分位抗反光 → 顶层净高与遮挡拓扑判定 |
| **单根芦笋测量** | 白根长度不一、视角缩放、无深度图时缺乏绝对尺度 | 物理尺度三级解析（深度+内参 → AprilTag 平面投影 → 手动 `mm/px`）；沿 PCA 中轴按固定根→尖方向定位白绿分界线，仅测绿色有效长度及向头部偏移 $20\text{ mm}$ 处截面直径 |
| **多视角空间建图** | 单目平面标靶 PnP 翻转歧义；机位近共面导致法向弱约束；单靶边长微小误差引发全局尺度漂移 | 多靶非共面空间散布 + 多视角大倾角拍摄 + 两阶段鲁棒 BA（Cauchy + MAD）+ 远距世界锚点 Umeyama 对齐 |
| **手机多摄标定** | 自动变焦/OIS/电子防抖导致等效内参漂移 | 锁定单一物理镜头、禁用数码变焦与防抖、固定分辨率与对焦距离（机理详见 [多摄变焦与标定稳定性机理.md](knowledge/多摄变焦与标定稳定性机理.md)） |

## 4. 不可违背的安全与数据红线

### 4.1 运动控制安全红线
- **SCARA 机械零位硬约束**：机械零位绝对坐标刚性绑定为 `(X0, Y600, Z80, R90°)`。
- **Marlin R 轴映射**：SCARA 旋转轴 $R$ 在 Marlin 固件中映射至 `E` 轴；设零命令必须发送 `G92 X0.00 Y600.00 Z80.00 E90.00`，**严禁**使用 `G92 X0 Y0 Z0`。
- **设零三步串行**：`M84`（释放电机）→ `G92`（写入零点）→ `M114`（回读确认）。
- **抓取熔断保护**：外参异常或目标抓取高度越界（$Z \notin [5, 45]\text{ mm}$）时必须立即拦截，严禁输出下探 G-code。
- **三段式防撞轨迹**：任何拾取/放料水平平移前必须先抬升至 `safe_z`（默认 `80.0 mm`），垂直下探后再闭合夹爪并保压延时（`G4 P200`）。
- **分离轮状态互锁**：仅当目标设备 MQTT 状态为 `idle` 时受理 `load` 生产指令，严禁在 `running` / `offline` 状态强发。

### 4.2 数据与几何一致性红线
- **单一真理源（SSOT）**：严禁新旧配置格式双轨兼容或隐式硬编码兜底（如 `tag_default_size_mm` 缺失必须显式报错，严禁静默回退 `50.0`）。
- **硬件与分辨率锁定**：工位一旦存在历史采图即锁定相机类型与物理分辨率；传入图像分辨率与工位规格不一致时必须拒绝，杜绝跨分辨率内参错配。
- **跨平台路径安全**：所有图像读写统一走 `src/utils/image_io.py`（`imread_unicode` / `imwrite_unicode`），防止 Windows 中文路径下 OpenCV 崩溃。
- **零测试污染**：单元测试严禁读写真实 `config/gui_settings.json` 或生产工位数据目录。
